# Copista（配布用）

Copista は Windows 用のクリップボード履歴・定型文ツールです。このリポジトリは**配布専用**で、ソースコードは置いていません。

## 入手方法

1. [最新のリリース](https://github.com/hephaestus-workers/copista-releases/releases/latest) から `Copista_<版>_x64-setup.exe` をダウンロードします。
2. ダウンロードしたファイルを実行します（管理者権限は要りません）。コード署名証明書を使っていないため、初回に Windows SmartScreen の警告が出ることがあります。その場合は「詳細情報」→「実行」で進めてください。
3. 以降の更新は、Copista が起動時（またはトレイの「更新を確認」）に知らせます。承諾すると自動で入れ替わり、再起動します。
